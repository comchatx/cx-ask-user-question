When cx needs you to decide, it puts its questions on a card in the chat, each with options to pick. You can also write your own answer or skip. Where a yes or no is enough, the card asks only that. It stays until you answer, and you can still send messages.

This plugin is made for the ComChatX chat page, which draws its questions as one card.

Some things you can ask:

- Which product should I push next month? Give me a few options to choose from.
- Before you write the listing, ask me everything I need to decide, in one go.
- Where you're unsure how deep the promotion should go, ask me before you settle it.
